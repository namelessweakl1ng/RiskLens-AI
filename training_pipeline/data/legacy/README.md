# Quarantined prototype data

These files are retained to preserve original work, **not ground truth**.
`card_labeled.jsonl` and `card_split/` were generated by keyword/regex rules:
2,857 weak labels across 60 source filenames. Their old clause-random split is
not safe for model evaluation. Original PDFs, hashes, observed URLs and retrieval
dates are absent; they cannot pass current provenance validation.

`reviewed_clauses.jsonl` contains two historical `source=human_review` claims.
The reviewer identity, source documents and retrieval metadata are unknown.
Those claims are preserved, not upgraded into verified review. Obtain the actual
source documents and auditable annotations before using them.

`card_clauses.jsonl` holds corresponding unannotated text. `clauses.jsonl` is empty.
The new pipeline rejects records missing provenance. Do not train on these files
or quote prototype split accuracy as a RiskLens benchmark.
